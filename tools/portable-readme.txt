校园通知 · 日程 — 便携版
=========================

1. 本目录的「bjut-news-grabber-0.0.1-portable.exe」是可执行文件，双击即可运行，
   无需安装，也无需解压。
2. 需要 Windows 10/11 与 Microsoft Edge WebView2 运行时。若缺少 WebView2，
   程序启动时会弹出官方安装地址提示，按提示安装后重新打开即可。
3. 通知与日程数据保存在 %APPDATA%\campus-notice\，不会随便携版目录移动。
   卸载：直接删除解压目录；如需同时清除数据，再删除上述目录。
4. 凭据优先保存在 Windows 凭据管理器，导出的数据文件不含 Cookie 与 API Key。

安装版（NSIS / MSI）与便携版内容一致，按需选择其一即可。
